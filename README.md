# Teacharcha

Teacharcha is a space for teachers to share their thoughts, ideas and resources.
It is maintained by Vicharanashala, the Lab for Education Design at IIT Ropar.

**Website:** https://vicharanashala.github.io/teacharcha/

## Why it exists

Teachers learn a great deal from one another, yet much of that learning stays inside
one staffroom or one programme. Teacharcha gives it a place to live and be found.

## What it will hold

The site will grow in stages:

1. **Now:** writing and resources added by the lab team.
2. **Next:** resources that teachers build or revise in the lab's programmes, credited
   to the teacher and their institution.
3. **Later:** a podcast, and lab videos that suit Teacharcha better than the lab's
   other programmes.

For now Teacharcha sits alongside the lab website at https://vicharanashala.ai.
It may become a website of its own later.

## Who looks after it

The lab team maintains the site and decides what goes on it. If you would like to
suggest a resource, contact the lab through https://vicharanashala.ai/contact/.

## How the site is built

This is a simple website, not an app. It uses Jekyll, the same tool and the same look
as the lab website, and GitHub publishes it automatically.

| To change... | Edit this file |
|---|---|
| The home page | `index.md` |
| The menu at the top | `_includes/header.html` |
| The site title and description | `_config.yml` |
| Colours, fonts and spacing | `_sass/minima.scss` (copied from the lab website) |

Changes to `main` appear on the website within a few minutes.

**Keeping the look in step with the lab site:** the styles in `_sass/` were copied
from the `vicharanashala-ai` repository on 14 October 2026. If the lab site's look
changes, copy the updated `_sass/` folder across.
